# Project screenshots

Drop images into the folder named after the project (its case-study URL, e.g. `/work/akulas-kitchen` → `akulas-kitchen/`). They show up on that project's page automatically; no code changes needed.

| File name | Where it appears |
| --- | --- |
| `store-01-home.png` | **Mobile** tab, shown as-is. Use this for finished Play Store / App Store images. |
| `mobile-01-home.webp` | **Mobile** tab, inside a phone frame. Use this for a raw phone screenshot. |
| `desktop-01-landing-page.webp` | **Desktop** tab, inside a browser window. Use this for a raw desktop screenshot. |

- **Order:** the number sets the order (`01`, `02`, …).
- **Caption:** the words after the number become the caption: `mobile-02-order-tracking.webp` → "Order tracking".
- **Formats:** `.png`, `.jpg`, `.webp` and `.avif` all work. `.webp` keeps pages fastest.
- **Size:**
  - Phone screenshots: about 1170×2532 (any tall phone ratio is fine).
  - Desktop screenshots: about 2880×1800 (16:10).

Until a tab has images, the page shows placeholder frames. On localhost those placeholders also tell you which file name to use.
